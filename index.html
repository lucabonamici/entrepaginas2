Como já tens Firebase configurado, demora 3 comandos:

1. Instala as ferramentas: npm install -g firebase-tools
2. Login: firebase login
3. Na pasta da app: firebase init hosting

   → Diretório público: . (ponto)
   → SPA: Yes
   → Não sobrescrever index.html
4. Publicar: firebase deploy
